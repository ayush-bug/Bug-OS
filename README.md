# some source used in the project

I have create logo using chat gpt and designed it in canva for wallpaper .

I have created all the logo of os using chat gpt. (logo only not icon)

And use this tool `https://www.w3schools.com/tools/tool_css_glassmorphism.php` to give my taskbar glassmorphism look.

I have used bootstrap icons `https://icons.getbootstrap.com/`.

For all Ascii text art I have used `https://patorjk.com/software/taag/` .

`z-index.js` code is made with the help of  chatgpt.

some fonts are taken from google fonts.

The dragging window is copy past of w3school code `https://www.w3schools.com/howto/howto_js_draggable.asp`

And when I get problem or error that I was not able to understand for that I used google and chatgpt.
